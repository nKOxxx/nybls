## Q4 - label B
Answer: bend = "4b5": fret 4 of the G string, bend up until it sounds like fret 5 (B = bend). Bend release = "4b5r4": bend then release back to normal note in one pick ("BR" in speech). Pre-bend = "5pb4": pick the string already bent, then bring it down to the normal note.
Evidence: speech [08:57]-[10:10] "this 4B ... bend it up until it sounds like the fifth fret of the G string", "BR ... release the bend", "PB. This is a pre-bend ... pick the string while it's already bent". Notation on screen: g_00580s.png (4b5 and 5pb4 in the tab), g_00630s.png (4b5r4), g_00640s.png.
Key terms: 4b5, 4b5r4, 5pb4, G string.
Partial: meanings correct without the written forms, or forms without meanings. Speech alone gives only "4B", "BR", "PB", so the exact 4b5r4 and 5pb4 spellings need the frames.

## Q6 - label S
Answer: alternatives: letter "p" written between the numbers (e.g. 7p5), or the slur/arc symbol (same one used for hammer-ons, sometimes with a P above). Hammer-ons likewise may use "h" instead of the arc. Tell them apart by direction: you can't hammer on to a lower note, so going to a lower number = pull-off.
Evidence: transcript [07:07]-[07:32] "Some tabs will use an H ... Sometimes you'll see it written just as a P ... written with the same symbol we use for the hammer on ... you can't hammer on to a lower note." Frame g_00440s.png titled "2 WAYS TO WRITE PULL OFFS" shows 7p5 and an arc over 7 to 5 with P above (frame time approximate; frame at about 07:00-07:30).
Partial: "P letter or arc" without the how-to-tell rule.

## Q8 - label S
